User guide

  1. Download the source from the GitHub repository.
  2. Read the license, then choose the plugin/ folder in a platform that supports local plugins. If you need a ZIP, run python scripts/package.py from the repository folder.
  3. Check that the platform recognizes all 13 skills and try a simple request. Installation depends on the product and platform version and has not been fully tested in every environment.
  4. State the objective, the party being assisted, the event dates, the documents and the desired outcome. Provide only data you have the right to use.
  5. Check the deciding sources, validity and limits before using the result.

The instructions may use the search tools already available; they do not install tools or create database connections by themselves. Without tools, a conditional output and a verification plan are needed.
