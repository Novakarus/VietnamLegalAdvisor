Testing and limits

Latest round: round 6, 2026-11-11, on version 0.70.2 (candidate; not public). 22 isolated Claude Code subagent sessions, one per case, with only Read/Edit tools (no web or shell), reading the plugin unpacked from the 0.70.2 package. 22/22 cases passed a provisional AI grading by Claude, with no critical or major defects; the minor defects of round 5 were fixed except two skills not read (D01, D02). Round 5 (2026-11-10, version 0.70.1, accepted) gave 22/22 too.

Round 5 details: same method on the 0.70.1 package. 22/22 cases passed a provisional AI grading by Claude, the same vendor as the runner, with no critical or major defects. A first attempt on the real Codex host completed one case before the account reached its usage limit. This is not an independent legal review or a full verification against current law.

Round 4 (2026-11-04, version 0.70.0) gave the same result. Earlier rounds 1–3 were run by Codex on version 0.69.3, which has since been removed from the repository together with their records (still available in the Git history).

Limits: the Protocol v2 integrity check still has two errors (the grader is from the same vendor as the runner, and the plugin has not been run on a real production host); there is no lawyer review and no live cases with answer keys; the subagents used the system prompt of the agent type that configures the status line, not that of a product host. Do not read a provisional PASS as a guarantee of legal correctness or a quality certification.
