Testing and limits

Latest round: round 4, 2026-11-04, on version 0.70.0 (a candidate that is not public). 22 isolated Claude Code subagent sessions, one per case, with only Read/Edit tools (no web or shell). 22/22 cases passed a provisional AI grading by Claude, the same model family as the runner; 14/14 technical checks passed. This is not an independent legal acceptance or a full verification against current law.

Earlier rounds 1–3 (2026-10-20 and 2026-10-21) were run by Codex on version 0.69.3, which has since been removed from the repository; their records are kept as history. Round 5 on a real host (Codex) is in preparation and has not been graded.

Limits: the Protocol v2 integrity check still has two errors (the grader is from the same vendor as the runner, and the plugin has not been run on a real production host); there is no lawyer review and no live cases with answer keys; the subagents used the system prompt of the agent type that configures the status line, not that of a product host. Do not read a provisional PASS as a guarantee of legal correctness or a quality certification.
